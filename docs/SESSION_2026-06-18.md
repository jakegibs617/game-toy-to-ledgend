# Development Session — 2026-06-18

A development pass on **Toy to Legend** (Godot 4.6). Three features shipped
to `main`, each as its own branch → PR → multi-angle review → squash merge,
with the headless smoke test extended alongside every feature and 3 clean
smoke runs + 1 windowed boot per PR.

## Shipped this session

### 1. Street benches — sit to sketch tag styles (PR #33)
Closes the Product_reqs.md "sit on a bench to sketch/practice styles" item.

- Data-driven benches (`Data/benches.json`, `Scripts/World/bench.gd`) on the
  `interactable` protocol — two in Mill Yard, one in Canal Side.
- Interacting seats the player (`Player.begin_sit`), suppresses movement,
  plays the imported seated rooster clip, then drops to **first person** and
  opens the blackbook in a new **practice mode**: number keys sketch the tag
  styles still worth practicing (one page per press, delegating to
  `GameState.practice_tag_font_style`). Closing the book stands the player up.
- New decoupling signals `sit_practice_requested` / `sit_practice_ended`.

### 2. Milestone 31 — performance & runtime budget pass (PR #34)
The next clean v3 milestone (Plan_v3.md §3.4 / M31).

- `PlaytestMetrics.runtime_budget_snapshot()` / `runtime_budget_summary_text()`
  record world node count, a node-type histogram, mesh/wall/train/interactable
  counts, the M24 material-cache size, character-visual import status
  (`Player.visual_report()` → animated/static/capsule), and a live
  `Performance` frame readout.
- Documented soft desktop budgets (`RUNTIME_BUDGETS`) that flag `overBudget`
  categories; the smoke test fails if the built city exceeds them.
- Dormant in normal play; `RUNTIME_BUDGET=1` prints once after the world
  builds. `docs/PERFORMANCE_BUDGETS.md` records targets and findings (current
  build ≈ 3,660 world nodes / 2,110 meshes — street detail dominates).

### 3. Bespoke scratch/acid tag-style behaviors (PR #35)
Closes the Product_reqs.md 🟡 items where style data flags weren't consumed.

- **Glass-only gating** for scratch + acid hands via
  `WallManager.font_style_block_reason`.

- New `glass` surface type + a `territoryNeutral` **Corner Store Window** in

### Close remaining Product_reqs.md items

4. **Wildstyle heaven-spot payoff.** Consume the `exposure: 1.35` wildstyle
   flag: longer paint time + higher heat, but a rep multiplier when placed on a
   high-visibility "heaven spot" (rooftop/landmark wall), making wildstyle a
   real risk/reward choice.

   short social beat (recruit leads, cool off heat, hear rumors about rival
   moves) — the non-combat counterpart to battles.

### Systems depth (post-candidate)
